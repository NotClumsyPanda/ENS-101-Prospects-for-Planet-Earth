# Planet Prep | ENS 101

Interactive multiple-choice study website for **ENS 101: Prospects for Planet Earth**, Fall 2026.

## Features
- 56 multiple-choice questions across lectures 1–9
- Practice mode with immediate feedback and explanations
- Exam mode, lecture filters, randomized quizzes, and missed-question review
- Local browser progress tracking

## GitHub Pages
1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main**, folder **/(root)**, then **Save**.
4. Wait for GitHub to publish at https://notclumsypanda.github.io/ENS-101-Prospects-for-Planet-Earth/

Open `index.html` locally to use the site offline. Study content is supplementary and should be checked against course lecture slides.
